# AWS Cloud Project – Secure Website Hosting & Cloud Storage

## Project Description
This project demonstrates secure website hosting and cloud storage using Amazon Web Services (AWS).

## AWS Services Used
- **Amazon EC2:** Hosts the website.
- **Amazon S3:** Stores website backups.
- **AWS IAM:** Manages access permissions.
- **Amazon VPC:** Provides network infrastructure.
- **Amazon EBS:** Provides persistent storage.

## Key Features
- Cloud-based website hosting
- Secure AWS networking
- Website backup storage
- IAM-based access management
- Persistent cloud storage
